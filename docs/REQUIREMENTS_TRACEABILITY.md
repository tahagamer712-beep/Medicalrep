**القوائم الموجودة فعليًا (مربوطة وتعمل بالـ mocks):**
- /start و/menu → القائمة الرئيسية (7 أزرار)
- 📊 حالة النظام (شركات/مكاتب/مستخدمون/نسخ)
- 🏢 الشركات ← تفاصيل الشركة (+➕ مكتب جديد) ← المكاتب ← تفاصيل المكتب ← المندوبون ← تفاصيل مندوب (+⛔ إنهاء / 🔀 نقل)
- 📋 الخطط المعلقة ← المكاتب ← الخطط ← التفاصيل (+✅ اعتماد / ✏️ إرجاع للتعديل)
- 👥 المستخدمون (+➕ مستخدم جديد + إسناد عضوية)
- 🔍 بحث عن مندوب (نص حر ← نتائج ← تفاصيل)
- 📝 سجل التدقيق المركزي (ترقيم صفحات)
- 💾 النسخ الاحتياطية (حالة + تذكير المفاتيح)
